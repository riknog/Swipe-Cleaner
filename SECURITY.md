# Política de Segurança — SwipeCleaner

A equipe do SwipeCleaner leva a sério a segurança dos usuários e do aplicativo.

## 🛡️ Versões Suportadas

Apenas a versão mais recente do branch `main` e os últimos releases oficiais recebem atualizações de segurança.

| Versão | Suportada |
| --- | --- |
| Última Release / `main` | :white_check_mark: |
| Versões anteriores | :x: |

## 📢 Como Reportar uma Vulnerabilidade

> [!IMPORTANT]
> **Por favor, NÃO abra uma Issue pública para reportar falhas de segurança.**

Se você encontrou uma vulnerabilidade de segurança no SwipeCleaner:

1. **Relato Privado no GitHub**: Utilize a aba **Security** > **Report a vulnerability** no repositório GitHub para nos enviar os detalhes diretamente de forma privada.
2. **Prazo de Resposta**: Comprometemo-nos a analisar seu relato em até **48 horas** e fornecer atualizações periódicas até a resolução do problema.
3. **Divulgação Responsável**: Pedimos que aguarde a publicação da correção antes de divulgar qualquer detalhe técnico publicamente.

Agradecemos a comunidade por ajudar a manter o SwipeCleaner seguro!
